# Shadow Empire: 1800

> A game jam entry by [PRSro](https://github.com/PRSro) and [CodeMathe](https://github.com/CodeMathe)

---

## About

**Shadow Empire: 1800** is a game jam project set in the early 19th century. Built in C# with ASP.NET.

---

## Project Structure

```
Shadow Empire: 1800/    # Main game project
.gitignore              # Ignores AI agent directories

```

---

## Getting Started

### Prerequisites
- .NET SDK
- A C# compatible IDE (Visual Studio, Rider, or VS Code with C# extension)

### Run locally
```bash
git clone https://github.com/PRSro/Game-Jam-game.git
cd "Shadow Empire: 1800"
dotnet run
```
