# Seed Data

All data in this directory is **DEMO DATA - ORIGINAL PLACEHOLDERS**.
These files contain fictional/example data for development and testing only.
They are clearly marked as demo data and not scraped from any external source.

Contents:
- places.json - Sample places in Bucharest
- events.json - Sample events
- businesses.json - Sample local businesses
- job-ads.json - Sample job advertisements
- traffic-disruptions.json - Sample traffic alerts
- polls.json - Sample polls
- neighborhoods.json - Sample neighborhoods

Generated for Piața (Bucharest living map). All content is original.
