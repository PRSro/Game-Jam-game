# Image Policy

## Guidelines
- Prefer organizer-uploaded images with explicit license grant in terms
- Fallback to generated placeholder (Belle Époque style by category/date/neighborhood) when no image
- For imported events: store sourceUrl + imageUrl (hotlink) only if source permits; otherwise skip image
- Attendee photos require consent checkbox, report button, fast takedown; avoid children images
- Openly licensed (Wikimedia Commons, Unsplash) allowed with attribution
- Never copy full image assets without permission
- Hotlinking can break if URL changes; consider caching policy

## GDPR notes
- Photos of identifiable people = personal data
- Event photo notice may be needed
- Honor removal requests promptly
